
# UniFIND User Flows

## Student Lost Item Flow

Student loses item  
↓  
Opens UniFIND  
↓  
Searches or browses found items  
↓  
If the item is found → View item → Submit claim → Provide description and evidence → Admin review → Approved or rejected → If approved, collect item  

If the item is not found → Submit lost-item report → Report is stored → Student can check again later if the item is found

## Finder Flow

Finder finds an item  
↓  
Opens UniFIND  
↓  
Submits found-item form  
↓  
Uploads photo  
↓  
Provides basic item details  
↓  
Provides private identifying details  
↓  
Submits item  
↓  
Admin reviews submission  
↓  
Item becomes publicly searchable

## Admin Flow

Admin signs in  
↓  
Opens admin dashboard  
↓  
Views found items, lost reports and claims  
↓  
Reviews claim information  
↓  
Compares claim with private finder details  
↓  
Approves or rejects claim  
↓  
Updates item status  
↓  
If approved, item is marked as collected
