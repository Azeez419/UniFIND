# UniFIND Requirements

## Functional Requirements

- FR1: The system shall allow university users to create an account and sign in.
- FR2: The system shall allow students to browse found items.
- FR3: The system shall allow students to search and filter found items.
- FR4: The system shall allow students to submit a lost-item report if they cannot find their item.
- FR5: The system shall allow finders to submit a found item using a simple form.
- FR6: The system shall allow finders to upload a photo of the found item.
- FR7: The system shall allow students to submit a claim for a found item.
- FR8: The system shall allow students to provide a description and evidence of ownership when claiming an item.
- FR9: The system shall allow administrators to view private found-item details.
- FR10: The system shall allow administrators to approve or reject claims.
- FR11: The system shall allow administrators to update an item status.
- FR12: The system shall allow students to view the status of their claims.

## Non-Functional Requirements

- NFR1: The system should be usable on both desktop and mobile devices.
- NFR2: Sensitive finder details must not be visible to normal users.
- NFR3: Only authorised administrators should be able to access private item and claim information.
- NFR4: User passwords and sensitive data should be stored securely.
- NFR5: The main browsing and search pages should respond quickly under normal use.
- NFR6: The interface should use clear labels and simple forms.
- NFR7: The system should validate required fields before accepting submissions.
- NFR8: The system should keep a record of important claim and status changes.

## User Stories

- As a student, I want to search found items so that I can check whether my lost property has already been handed in.
- As a student, I want to report an item as lost if I cannot find it so that there is a record if it is found later.
- As a finder, I want to submit a found item quickly so that reporting it does not take too much time.
- As a student, I want to claim an item and provide evidence so that I can prove it belongs to me.
- As an administrator, I want to view private finder information so that I can verify claims without exposing sensitive details publicly.
- As an administrator, I want to approve or reject claims so that items are only returned to genuine owners.
