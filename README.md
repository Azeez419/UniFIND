# UniFIND


UniFIND is a university lost-property web application designed to help students search for found items, report missing property, and securely claim items that belong to them.

## Project Purpose

The aim of UniFIND is to provide a simple and secure system for managing lost property within a university environment.

Students will be encouraged to search through found items first. If their item has not been found, they can submit a lost-item report so that a record exists in case the item is found later.

People who find lost property will be able to submit the item through a quick and simple form. Sensitive information provided by the finder, such as the exact location and identifying details, will remain private and will only be available to administrators.

Students who believe they have found their item can submit a claim and provide their own description and evidence of ownership. Administrators will review the claim before approving or rejecting it.

## Main Users

- Students who have lost an item
- People who have found an item
- Administrators who manage items and claims

## Core Features

- Browse and search found items
- Filter items by category and other details
- Submit a lost-item report
- Submit a found item
- Upload item photos
- Submit a claim
- Provide evidence of ownership
- Admin claim verification
- Approve or reject claims
- Track item and claim status
- Protect private item information

## Main Workflow

Lost something → Search found items → If not found, submit lost report → Item may be found later → Claim item → Admin verifies claim → Item is returned to the owner.

## Project Status

 Planning and requirements stage.

The project is currently being defined and designed before development begins.

## Future Development

Possible future features may include:

- AI assistant to help users search, report and claim items
- Automatic matching between lost reports and found items
- Notifications for possible matches
- Image-based item matching
